Obscura opens images and PDFs directly in your browser, automatically scans them for things like emails, phone numbers, card numbers and ID numbers, and shows you exactly what it found before touching anything. Confirm, adjust, or mark more by hand — then it strips the hidden metadata too and hands you back a clean file. No server, no upload, no account.

  2. 02

    Review what it found

    Every match is shown before anything is hidden. Uncheck false positives, accept the rest, and draw over anything it missed — a click removes a mark.

  3. 03

    Download, in order

    Hidden metadata is stripped automatically, each file is numbered by upload order, and it's saved to your local history.

Nothing you open here is ever sent anywhere. Obscura runs entirely as JavaScript in this browser tab — file reading, redacting, re-encoding and history storage all happen locally. The page's own fonts/icons are the only network requests involved, and can be removed for a fully offline copy (see the README).
